## 人工检查清单

1. 双击 EXE，确认窗口正常显示，中文、按钮、字段表及说明没有遮挡或截断。
2. 保持自动识别，粘贴 `examples/mixed-continuous.hex`，确认点击前不解析；点击“识别并解析”后显示三条，分别选择第二、第三条并点 DI 核对高亮。
3. 载入“645 电能应答示例”后点击识别，确认显示 `123456.78 kWh`；修改一字节再点击，确认校验错误被显示。
4. 在组装页选择规约、修改参数并生成报文，送到解析页后再次点击识别；本地 C=`60` 时应启用两个地址框。
5. 检查文本导入、全部解析报告导出、小窗口滚动及实际使用的 DPI；末尾补齐半帧 / 半字节后再次点击，确认完整解析且原始输入不变。
