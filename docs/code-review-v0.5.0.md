# 0.5.0 Code Review 记录

日期：2026-10-28。基线：`1f48d4d`（`v0.4.1`）。

## 审查与改动

识别回显原本不能直接复用规约下拉框的变更事件，因为该事件会清除结果并重置组帧参数。现区分用户配置与识别显示：程序回显跳过重置路径，组帧页恢复已配置规约；多帧选择变化只更新当前显示。未知、歧义和输入更新不会保留过期识别结果。

新增 `BusinessDecoder.cs`，集中放置已核对的控制位、DI 名称及业务解释；解析、组帧和分帧仍使用既有入口。审查核对了 BCD/BIN/ASCII 的差异、645 的 ±33H、符号与单位、时间顺序、字段偏移、上下行方向及长度边界。`FrameStream.cs` 无修改，长度和 CS 算法不变。

业务异常只增加解释或说明，不改写原始字节，也不将业务数据缺失直接判定为帧结构错误。未知项目不返回伪造数值。上行只解码已知首信息体长度；整个应用业务区继续保留，不把读取请求、认证尾部或加密写参数按普通电能数据解释。

审查范围内没有剩余的已确认 P1 / P2 问题。当前覆盖及未实现项目详见 [字段解码范围](decoding.md)，不代表所有标准附录和真实设备验收通过。
