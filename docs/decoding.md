# 0.5.0 字段解码范围

依据本机 [标准清单](../specifications/README.md)，不把参考项目的其他规约或数据字典当作本项目的标准。业务解释显示在“解读”列及展开字段中，原始字节和偏移保持不变。

## 规约回显

勾选自动识别时，顶部框显示当前帧识别结果并保持不可选：单帧识别成功后显示，多帧随摘要选中行更新。尚未识别、未知或歧义片段不显示上次的结果。回显不触发输入重新解析、结果清空或组帧参数重置；手动及组帧配置独立保留。

## 645

依据第 5～7 章、附录 A 和附录 C；对数据域先减 33H，再按 DI 和命令方向解释。读请求不会被当作数值应答。

| 字段 / 数据项 | 当前解释 |
| --- | --- |
| 控制码 | DIR、正常/异常应答标志、后续帧标志、功能码名称；包括读写、校时、清零、跳合闸/报警/保电、端子输出等 |
| ERR | 其他错误、无请求数据、密码错/未授权、速率不能更改、年时区/日时段/费率数超限及保留位 |
| 电能 | `00` 类中组合/正向/反向有功、组合无功1/2、四象限无功、正反向视在；总及费率1～63、当前及上1～12结算日，4字节 BCD、2位小数 |
| 电压、电流 | `0201` / `0202` 三相；V 为2字节1位小数，A 为3字节3位小数，电流识别方向符号位 |
| 功率、功率因数 | `0203～0206`，总及分相；3字节4位小数功率，2字节3位小数功率因数，识别符号位 |
| 相角、失真度、谐波 | `0207～020B` 已定义单项；相角1位小数、百分比2位小数 |
| 其他常用变量 | `02800001～0280000B`：零线电流、频率、平均功率、当前需量、温度、电池电压/时间、阶梯电价 |
| 日期及时间 | `04000101` 日期及星期，`04000102` 时间；按规约两位年份 YY 输出 |
| 数据块 | 645 电能费率块，以及电压、电流、功率、功率因数、相角、失真度的已知相/总值块；长度不符时不猜测布局 |
| 特定命令内容 | 广播校时、写通信地址、多功能端子输出类别 |

尚未完整解释最大需量及发生时间、冻结、事件、负荷记录、密码/操作者代码、安全认证及全部写命令内容。

## 南网本地

依据功能总表、DI 编码规则和对应数据内容定义，收录 **108 项 DI 名称**。DI3 区分集中器/采集器，DI2 解释上下行及内容类型，DI1 对应 AFN。补充采集器 `23H/24H/25H` 和无线维护 `10H` 的 AFN 名称。

| 类别 | 已实现的数据内容 |
| --- | --- |
| 确认/否认 | 等待秒数、错误状态码及原因 |
| 模块信息 | 厂商/芯片 ASCII、版本日期/版本号 BCD；30字节运行模式中的通信方式、报文/分包长度、升级等待、主节点及节点容量 |
| 节点信息 | 数量、主节点/从节点/父节点地址、节点列表、注册状态、链路质量、通信延时和报文长度 |
| 开关、探测 | 即插即用、事件上报、采集器/转换器类型、表及映射表探测状态 |
| 任务 | 未完成/可分配数量、查询起始序号/数量、任务 ID、分优先级建议超时、任务执行状态 |
| 时间 | 集中器时间、CCO 时钟，按秒分时日月年传输顺序解释 |

BIN 数值低字节先传，地址以高字节在前的字符串显示；不执行 ±33H。数据方向不符、DI1 与 AFN 不一致或内容长度不符时停止该业务值解码，并保留原值。复杂任务、映射结构、文件传输及厂商自定义内容仍显示名称和原始值。

原文部分功能总表与详细子节的编码存在差异，例如文件传输失败节点。此类条目名称按功能总表收录，不据冲突条文猜测数值布局。

## 南网上行

依据本机 2024版V2.0 的第5章、6.1、6.2和附录 A/C。分别解释 DIR、PRM、下行 FCB/FCV、上行 ACD、按 PRM 定义的链路服务，以及 SEQ 的首末帧、确认和时标含义。

仅对已核对的明文 AFN `00/02/0A/0C` 解释首个信息体：

- `00`：确认/否定结果，包括 `E0000000` 全部肯定/否定；保留被确认 DI 的名称。
- `02`：登录的规约版本、安全模块标志和时间；心跳的可选时标、退出。
- `0A`：心跳周期、重拨间隔/次数、终端时间、APN/用户名/密码 ASCII，以及 TCP/UDP、压缩、心跳时标选项。
- `0C`：已核对的常用电能、电压、电流、功率等单项，以及终端节点/端口数量等；不做减 33H。线电压、基波和相位角按本机附录 C 的扩展名称解释。

读取请求中的后续 DA/DI 不会被误当作应答数据。已知首项只消费标准规定的长度，剩余字节完整保留，不猜测后续信息体或认证域。上行费率块、历史/事件/任务等其他复合布局尚未完整解码；PW/MAC 不计算、不验证、不解密。Tp 解读为日时分秒及允许传输延时，不验证时效。

## 缺失值与构造示例

全 FF 缺失标记、无效 BCD、未知 DI、方向/长度问题会在“解读”列说明。它们不被伪造为正常数值，也不把业务解释错误混同于帧结构校验错误。

- [645 电能应答](../examples/645-energy-response.hex)：`123456.78 kWh`。
- [本地模块版本应答](../examples/local-version-response.hex)：厂商 `AB`、芯片 `CD`、日期 `26-10-28`、版本 `1234`。
- [上行电能应答](../examples/uplink-energy-response.hex)：同一电能值，原始业务字节是 `78 56 34 12`，不减 33H。

这些是构造向量，不是真实设备抓包。自动回归及实机验证边界见 [验证记录](verification.md)。
