## 本版修复

视觉核对发现最小窗口下多帧内容被裁切：外层布局可用宽度为 950 像素，默认自动列仍根据分栏控件保留 1100 像素，输入和右侧详情超出容器。将该列明确设为 100% 宽度，摘要栏在缩放时保持宽度，字段解释列保留最低宽度并提供水平滚动。补充回归逐层检查输入、分栏、字段表和主题按钮都处于父容器边界内。

同时修正了原生页签在暗色下留下浅色空白区域，以及收紧标题栏后主题按钮高度超出容器的问题。页签采用现有控件的绘制入口完成背景和小圆角处理，主题按钮保留提示及可访问名称。
