# FrameTools 0.6.0

发布日期：2026-10-30。Windows 10/11，需.NET Framework 4.8；下载EXE后直接运行，无需Python、Node.js或外部XML。

- 三规约按用途组帧，共67个入口：645为7个、本地通信为42个、上行为18个。
- 日期、时间、周期、模式、节点列表和任务类型可视化填写，支持按名称检索上行数据项；保留原始HEX入口。
- 内嵌南网本地及上行XML，按AFN和方向选择明确的字段布局；完整原文资料保持本机保存。
- 修复任务模式切换可能将非法类型单元格误转成有效参数的问题。
- 窗口标题、右上角、导出报告和EXE版本统一为0.6.0（文件/程序集为0.6.0.0）。

上行设置生成待加密和PW/MAC认证的参数明文；本版未接入认证模块或设备收发，不代表完成真实设备联调。

构建验证及已知边界见 [验证记录](verification.md)，用途清单及截图见 [使用说明](purpose-composer.md)。

Git源码使用 `v0.6.0` 标签定位；本机同时保留 `artifacts/FrameTools.exe` 和便于区分版本的 `artifacts/FrameTools-v0.6.0.exe`。
