# 0.3.0 启动和界面记录

日期：2026-10-28。

## 交互调整

启动为空白工作区，构造过程不再加载和解析示例。输入、追加、示例载入、文件打开、模式切换和送入解析页均只更新输入或状态。只有“识别并解析”按钮及 Ctrl+Enter 触发匹配和分帧，输入定时器已移除。

解析页勾选自动识别后禁用手动规约下拉框；取消勾选后可手选。组帧页隐藏开关、将同一下拉框恢复为“组帧规约”，返回解析页恢复所选模式。协议和分帧核心没有改动。

启动时也不再为非本地规约的地址开关状态进入 HEX 解析路径；本地 ADD 位逻辑保持不变。

## 本机初始化测量

每版各运行 5 个新进程，使用同一探针创建窗体并准备指定解析控件的句柄及布局。辅助进程隐藏，不展示测量窗体。下表为中位数：

| 指标 | v0.2.1 | v0.3.0 |
| --- | --- | --- |
| 窗体构造 | 745.532 ms | 701.672 ms |
| 解析控件句柄准备 | 202.043 ms | 35.001 ms |
| 初始化总计 | 977.396 ms | 762.717 ms |
| 外部进程墙钟耗时 | 1152.644 ms | 927.948 ms |

初始化中位数减少 214.679 ms，约 **21.96%**。新版初始化总计范围为 760.241～782.029 ms。每次新版启动原始输入均为 0 字符、字段 0 项、片段 0 条；旧版会加载 59 字符、10 个字段和 1 个片段的示例。

这些是本机控件初始化测量，不包含首次可见绘制，没有清空操作系统缓存，不能等同于所有机器上的完整冷启动。各阶段中位数分别统计，因此它们的简单相加不必等于总计中位数。

原始探针及结果保留在本机 `.work/startup-measure/`，不纳入源码上传。

## 界面核对

界面采用浅灰分组背景、白色编辑面、系统蓝主操作、圆角按钮与开关、分段页签。原文与整形并排显示，规约状态更明确。组件仍继承原生 Button、CheckBox 和 TabControl，保留键盘与辅助功能语义。

已使用构造样例查看 1240×960 的解析 / 组帧预览、空白启动预览以及 1000×800 的组帧预览。较小窗口下组帧内容可以滚动，业务编辑区保留最低高度，不再被压缩到无法使用。

预览由本程序自身离屏绘制，不是其他应用或桌面的截图。它可核对层级、留白和内容空间，但不替代实际桌面的鼠标操作、多 DPI、系统主题及设备联调。
